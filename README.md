# Example-of-Character-Correction-Application
  --OCR校对工具
## 项目简介：
OCR识别及校对程序的桌面版本，提供了图形化用户界面的样例。

## 功能简述：
1. 实现了文字校对功能，预留了OCR识别引擎接口，可以对OCR识别结果进行修正校对，并保存结果。
2. 用户可点击上传按钮选择需要处理的图片，选择相应的识别引擎，点击识别。（识别引擎待后续接入）
3. 识别结果会按行排列，用户可以选择各个汉字并进行校对，也可勾选标注或填写备注，最后可以选择目录，保存校对结果。

## 更新计划：
1. 校对结果文件，可以自定义为特殊文件格式，待用户保存后，可以在GUI中读取上一次保存的文件继续工作。
2. 针对不同OCR引擎，其识别方式或许不同，文字校对时，排列方式可选择为按列排布或按行排布。
